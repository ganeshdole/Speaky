## Speaky has its own look

Speaky now has a face of its own: a blue speech bubble, saying something. You'll see it in your dock, in the menu bar, and when you set Speaky up.

![Speaky's new icon: a blue speech bubble talking, on a sky tile](/release-notes/0.10.1/speaky-icon.png)

Speaky is built on [Handy](https://handy.computer) by CJ Pais, and Handy's glove belongs to Handy, so Speaky's colours are blue now too.

## Updates from Speaky's own server

Speaky now checks for new versions on its own server first, with GitHub as the backup, so updates keep coming if either one is down. The latest version is always at [speaky.ganeshdole.com](https://speaky.ganeshdole.com).
